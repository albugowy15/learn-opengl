# Lesson 1.1: Triangle

Draws one triangle with three positions stored in a vertex buffer object (VBO).
The vertex array object (VAO) records how shader attribute location `0` reads
three `float` values for each vertex from that VBO.

Build and run from the repository root:

```sh
cmake --build build --target lesson_1_1_triangle
./build/lesson_1_1_triangle
```
